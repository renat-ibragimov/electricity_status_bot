# electricity_status_bot

Весь контекст проекта (архитектура, сервер, режимы миграции источника тревог,
деплой, откат, известные проблемы) — в [README.md](README.md). Прочитай его
первым.

Коротко:
- Сервер общий с чужими сервисами: трогать только `alert_status` (compose-проект),
  никаких `docker restart`/`compose down` по маске.
- Код на сервере без git и может расходиться с репой — перед деплоем стягивать и сравнивать.
- Секреты (`.env`, токены, `.session`) не читать и не выводить; имена переменных — можно.
- Выкладка на сервер — только после явного «да» от пользователя.
